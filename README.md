A seamless integration between WooCommerce and WowPay payment gateway that allows you to accept payments securely in your online store. 🔒

## ✨ Features

- 🚀 Easy setup and configuration
- 💰 Accept multiple payment methods through WowPay
- 🔄 Real-time payment status updates via webhooks
- 🛠️ Test mode for development and debugging
- 📊 Detailed transaction logging
- 🌍 Multi-language ready (i18n support)
- 📱 Mobile-friendly payment flow

## 📦 Installation

### Method 1: WordPress Admin Dashboard
1. Go to **Plugins → Add New** in your WordPress admin
2. Click **Upload Plugin**
3. Upload the `wowpay-woocommerce.zip` file
4. Click **Install Now**
5. Activate the plugin

### Method 2: Manual Installation via FTP
1. Download the plugin ZIP file
2. Extract the contents to your computer
3. Upload the `wowpay-woocommerce` folder to `/wp-content/plugins/`
4. Go to **Plugins** in your WordPress admin
5. Find **WooCommerce WowPay Gateway** and click **Activate**
